# **App Name**: Pranay Treading Co. Online

## Core Features:

- Shoe Catalog: Display a catalog of shoes with filtering and sorting options (by type, size, price, etc.) using dummy data.
- Contact Form: A simple contact form with fields for name, email, and message, submitted via email. Include company address and phone number.
- Shipping Information: Display a clear explanation of shipping costs and delivery times.

## Style Guidelines:

- Primary color: Dark blue (#003049) to convey trust and professionalism.
- Secondary color: Light gray (#D6D6D6) for backgrounds and subtle accents.
- Accent: Orange (#D62828) to highlight key elements and calls to action.
- Clean and modern layout with clear sections and intuitive navigation.
- Simple and professional icons for categories, filters, and other UI elements.
